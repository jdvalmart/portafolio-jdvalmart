# Architecture Decision Records

This directory records the significant architectural decisions made for the
portfolio, following the lightweight [ADR](https://adr.github.io/) format.

Each record captures the context, the decision, and its consequences. Decisions
that are superseded are not deleted; they are marked as such and linked to the
record that replaces them.
